# sample_data/ — Shared (OCR + CV + ML pull from here)

Put your 10+ sample FMCG package photos here for pipeline testing and for
the offline judge-demo fallback (so the live demo doesn't depend on
network/camera conditions alone).

Good sources to pull real label images from:
- Open Food Facts (India subset): https://world.openfoodfacts.org
- Your own phone photos of real packaged products (recommended — closer
  to real-world lighting/reflection conditions than curated datasets)

Actual image files are gitignored by default (see root `.gitignore`) to
keep the repo light — keep a local copy and share via a team drive link
if needed, or unignore individual sample files deliberately.
