Slide 02 • Core Idea & Innovation

Proposed Solution: Automated Legal Metrology Inspection

An end-to-end, edge-capable computer vision and OCR pipeline enforcing packaging statutory compliance.

🔍

Detailed Explanation

  • End-to-End Scan-to-Verdict: Field officers snap a photo of any FMCG package via a mobile-responsive PWA.
  • Computer Vision Normalization: Deskews curved/angled labels, reduces reflection, and crops declaration zones.
  • Self-Hosted Deep OCR: Runs lightweight PP-OCRv4 to extract multi-oriented text, currency, and quantities with pixel coordinates.
  • Rule 6 Legal Engine: Deterministically checks presence and formatting of all 6 statutory fields.
⚡

How It Addresses Problem

  • Eliminates Manual Bottlenecks: Replaces 15-minute manual ruler-and-magnifier checks with automated <2s verification.
  • Audit-Grade Evidence: Generates tamper-proof PDF inspection certificates with annotated visual bounding-box overlays.
  • Zero Cloud Token Costs: Operates entirely on self-hosted open-source models without expensive third-party APIs.
  • Eliminates Subjective Bias: Deterministic rules guarantee consistent enforcement across all districts.
💡

Innovation & Uniqueness

  • Explainable Compliance Engine: Unlike black-box LLMs that hallucinate, every violation cites exact statutory sub-clauses of Rule 6.
  • Multi-Line Proximity Windowing: Intelligently fuses split lines (e.g. "MRP" on line 1, "incl. of all taxes" on line 2).
  • In-Memory Zero-Copy Handoff: Direct memory array passing between CV and OCR eliminates disk latency and file garbage.
  • Dual-Fallback Resilience: Automatic failover to EasyOCR ensures 99.9% inspection availability in the field.

Slide 04 • Implementation Reality

Feasibility, Risks & Mitigation Strategies

A zero-cost, high-reliability design engineered for real-world Indian retail packaging conditions.

📊

Feasibility Analysis

  • Technical Feasibility: Working baseline already implemented and tested locally. Runs efficiently on standard commodity CPU instances without requiring GPU clusters.
  • Financial Viability: 100% Free-Tier architecture ($0 upfront / $0 recurring API cost). Highly scalable for state and central government budgets.
  • Operational Viability: Zero installation required for officers; runs as a lightweight PWA on any standard Android/iOS smartphone.
⚠️

Challenges & Risks

  • Reflective Foil Packaging: Glossy pouches (chips, detergents) produce light glare obscuring small text.
  • Curved Packaging Geometry: Bottles and aerosol cans distort text baselines.
  • Non-Standard & Faded Fonts: Dot-matrix inkjet printed manufacturing dates often blur.
  • Network Dropouts in Rural Markets: Low-connectivity retail environments in rural inspection drives.
🛡️

Mitigation Strategies

  • Bilateral Filtering & Adaptive Thresholding: Suppresses glare textures while sharpening character stroke boundaries.
  • Direction Classifier & Deskew: PaddleOCR angle-classification handles up to 180° tilted text orientations.
  • Dual-Engine Failover: Auto-triggers EasyOCR when PP-OCRv4 confidence drops below 0.50 threshold.
  • Human-in-the-Loop Review: Ambiguous labels flag a REVIEW status with highlighted regions for quick inspector confirmation.
